# POULTRIVA — Premium Poultry Nutrition

Official web application for **POULTRIVA**, the premium poultry feed supplements and nutrition brand associated with **SAGL Life Sciences Pvt. Ltd.**, Nashik, Maharashtra, India.

> **Nutrition • Health • Performance**

---

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) + [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Type Safety**: [TypeScript](https://www.typescriptlang.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## Getting Started

### Prerequisites

- Node.js (v20+ or v22 LTS recommended)
- npm

### Installation

```bash
npm install
```

### Development Server

Start the local development server at `http://localhost:8080`:

```bash
npm run dev
```

### Production Build

Create an optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Testing & Code Quality

```bash
# Run unit & component tests
npm run test

# Lint code
npm run lint

# Format codebase
npm run format
```

## Project Structure

```
├── public/                 # Static assets & favicons
├── src/
│   ├── assets/             # Brand imagery & media
│   ├── components/         # Reusable UI components & layouts
│   │   ├── site/           # Header, Footer, Logo, WhatsAppFloat
│   │   └── ui/             # Radix UI primitives & design tokens
│   ├── data/               # Product catalog, articles & site metadata
│   ├── routes/             # TanStack Start file-based routing
│   ├── lib/                # Utilities & helpers
│   ├── server.ts           # SSR server entry point
│   └── styles.css          # Design system & Tailwind CSS v4 definitions
├── vite.config.ts          # Vite build configuration
└── package.json            # Application dependencies and scripts
```
